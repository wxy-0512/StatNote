普通最小平方法 (Ordinary Least Squares, OLS)

計量經濟學實證因果推論的第一塊基石：從簡單線性迴歸展開，解析最小化殘差平方和（SSR）之常態方程式推導、古典高斯-馬可夫假定、BLUE 定理與教育報酬率之經濟詮釋。

一、觀念介紹 (Concept Introduction)

在經濟學與社會科學中，我們經常想探討兩個變數之間的關聯或因果效應：例如「多受一年教育，薪資會增加多少？」、「政府提高最低工資，是否會降低青少年就業率？」、「降價促銷如何影響商品銷售量？」。

由於現實世界充滿了隨機干擾（如個人天賦、景氣波動、家庭背景等不可觀察因素），經濟變數之間的關係很少是精確不變的幾何函數，而是呈現散佈在空間中的點群。為了在混亂的數據中找出最具代表性的「平均趨勢線」，高斯（Carl Friedrich Gauss）與勒讓德（Adrien-Marie Legendre）提出了普通最小平方法（Ordinary Least Squares, 簡稱 OLS）。

OLS 的核心思想非常純粹：在所有可能的直線中，挑選一條直線，使得所有觀測值到這條直線的垂直距離（殘差）的平方總和達到最小。這條「最合身」的直線，就是我們理解經濟現象規律與預測未來趨勢的最佳工具。

二、數學定義 (Mathematical Definition)

2.1 簡單線性迴歸母體模型 (Simple Linear Regression Model)

設有 $n$ 組橫斷面隨機抽樣觀測值 $(X_1, Y_1), (X_2, Y_2), \dots, (X_n, Y_n)$。簡單線性迴歸的母體模型定義為：

$$Y_i = \beta_0 + \beta_1 X_i + u_i, \quad i = 1, 2, \dots, n$$

各項變數與參數之嚴格定義如下：

  • $Y_i$：應變數（Dependent Variable / 被解釋變數），例如個人的薪資水準。
  • $X_i$：自變數（Independent Variable / 解釋變數），例如個人的受教育年數。
  • $\beta_0$：截距項參數（Intercept Parameter），代表當 $X_i = 0$ 時，$Y$ 的基準期望水平。
  • $\beta_1$：斜率參數（Slope Parameter），代表自變數 $X$ 每增加一個單位時，應變數 $Y$ 的邊際平均變動量：$\beta_1 = \frac{\Delta E[Y \mid X]}{\Delta X}$。
  • $u_i$：隨機誤差項（Error Term / 擾動項），包含所有影響 $Y$ 但未納入模型中的其他未觀察因素（如個人動機、運氣、健康等）。

2.2 樣本迴歸函數與殘差 (Sample Regression Function & Residuals)

由於母體參數 $\beta_0, \beta_1$ 無法直接觀察，我們利用抽樣數據估計出 $\hat{\beta}_0, \hat{\beta}_1$，得到樣本迴歸函數（Sample Regression Function, SRF）：

$$\hat{Y}_i = \hat{\beta}_0 + \hat{\beta}_1 X_i$$

其中 $\hat{Y}_i$ 稱為第 $i$ 個觀測值的配適值或預測值（Fitted Value）。

真實觀測值 $Y_i$ 與模型預測值 $\hat{Y}_i$ 之間的垂直差距，稱為第 $i$ 個觀測值的殘差（Residual） $\hat{u}_i$：

$$\hat{u}_i \equiv Y_i - \hat{Y}_i = Y_i - (\hat{\beta}_0 + \hat{\beta}_1 X_i)$$

2.3 最小平方準則 (Least Squares Criterion)

OLS 的目標是選取一組係數估計式 $(\hat{\beta}_0, \hat{\beta}_1)$，使殘差平方和（Sum of Squared Residuals, SSR）最小化：

$$\min_{\hat{\beta}_0, \hat{\beta}_1} \text{SSR}(\hat{\beta}_0, \hat{\beta}_1) \equiv \sum_{i=1}^{n} \hat{u}_i^2 = \sum_{i=1}^{n} \left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right)^2$$

為什麼使用平方？ 一方面避免正負殘差相互抵消，另一方面平方函數處處平滑連續且可微，且能對極端的大誤差施加較重的懲罰。

2.4 古典線性迴歸基本假設（高斯-馬可夫假定 Gauss-Markov Assumptions）

為了保證 OLS 估計式具備良好的統計性質，橫斷面計量分析依賴以下五大基本假定（$A_1 \sim A_5$）：

  1. 假定一（參數線性 Linearity in Parameters）：母體模型可以表達成參數的線性組合 $Y = \beta_0 + \beta_1 X + u$。
  2. 假定二（隨機抽樣 Random Sampling）：樣本資料 $\{(X_i, Y_i)\}_{i=1}^n$ 為來自母體的獨立同分佈隨機抽樣。
  3. 假定三（解釋變數具變異性 Sample Variation in $X$）：樣本中 $X$ 的值不可完全相同，即樣本變異數大於零：$\sum_{i=1}^n (X_i - \bar{X})^2 > 0$。
  4. 假定四（外生性假定 / 零條件平均 Zero Conditional Mean）：給定任何 $X$ 的數值，未觀測誤差項的條件期望值皆為零： $$E[u \mid X] = 0$$ （此假定是因果推論與 OLS 不偏性的核心！若 $X$ 與 $u$ 相關，則產生內生性 Endogeneity，導致估計偏誤）。
  5. 假定五（同質變異數 Homoskedasticity）：給定任何 $X$，誤差項的條件變異數為固定常數： $$\text{Var}(u \mid X) = \sigma^2$$

高斯-馬可夫定理（Gauss-Markov Theorem）：在假定一至五成立下，OLS 估計量是所有線性不偏估計量中變異數最小的，即最佳線性不偏估計量（BLUE, Best Linear Unbiased Estimator）。

三、重要公式 (Key Formulae)

📌 OLS 估計式與代數性質
$$\hat{\beta}_1 = \frac{\sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^n (X_i - \bar{X})^2} = \frac{\text{Cov}(X, Y)}{\text{Var}(X)}$$ $$\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$$ $$\sum_{i=1}^n \hat{u}_i = 0 \implies \bar{\hat{u}} = 0 \quad (\text{殘差平均數必為零})$$ $$\sum_{i=1}^n X_i \hat{u}_i = 0 \implies \text{Cov}(X, \hat{u}) = 0 \quad (\text{殘差與自變數正交})$$ $$\text{迴歸線必穿過樣本平均點 } (\bar{X}, \bar{Y})$$

符號意義說明：
• $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$：自變數之樣本平均數。
• $\bar{Y} = \frac{1}{n}\sum_{i=1}^n Y_i$：應變數之樣本平均數。
• $\hat{\beta}_1$：斜率估計式，即樣本共變異數與自變數樣本變異數的比值。
• $\hat{\beta}_0$：截距估計式。
• $\hat{u}_i$：最小平方法殘差。

四、詳細推導 (Detailed Derivation)

4.1 一階條件（常態方程式 Normal Equations）

目標函數為殘差平方和：

$$\text{SSR}(\hat{\beta}_0, \hat{\beta}_1) = \sum_{i=1}^{n} \left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right)^2$$

分別對未知參數 $\hat{\beta}_0$ 與 $\hat{\beta}_1$ 偏微分，並利用鏈鎖律：

\begin{aligned} \frac{\partial \text{SSR}}{\partial \hat{\beta}_0} &= \sum_{i=1}^n 2\left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right) \cdot (-1) = -2 \sum_{i=1}^n \left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right) \\ \frac{\partial \text{SSR}}{\partial \hat{\beta}_1} &= \sum_{i=1}^n 2\left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right) \cdot (-X_i) = -2 \sum_{i=1}^n X_i \left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right) \end{aligned}

令一階偏導數等於零（FOC），將 $-2$ 除掉，得到經典的常態方程式系統（Normal Equations）：

$$\sum_{i=1}^n \left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right) = 0 \implies \sum_{i=1}^n \hat{u}_i = 0 \quad \text{--- (式 1)}$$ $$\sum_{i=1}^n X_i \left( Y_i - \hat{\beta}_0 - \hat{\beta}_1 X_i \right) = 0 \implies \sum_{i=1}^n X_i \hat{u}_i = 0 \quad \text{--- (式 2)}$$

4.2 求解截距估計式 $\hat{\beta}_0$

展開式 1：

$$\sum_{i=1}^n Y_i - \sum_{i=1}^n \hat{\beta}_0 - \hat{\beta}_1 \sum_{i=1}^n X_i = 0$$

注意 $\sum_{i=1}^n \hat{\beta}_0 = n \hat{\beta}_0$：

$$\sum_{i=1}^n Y_i - n\hat{\beta}_0 - \hat{\beta}_1 \sum_{i=1}^n X_i = 0$$

全式除以樣本容量 $n$：

$$\bar{Y} - \hat{\beta}_0 - \hat{\beta}_1 \bar{X} = 0 \implies \hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$$

結論：只要給定斜率 $\hat{\beta}_1$，截距項直接由平均值點 $(\bar{X}, \bar{Y})$ 決定，這也證明了迴歸直線必然通過樣本中心點。

4.3 求解斜率估計式 $\hat{\beta}_1$

將 $\hat{\beta}_0 = \bar{Y} - \hat{\beta}_1 \bar{X}$ 代入式 2：

$$\sum_{i=1}^n X_i \left[ Y_i - (\bar{Y} - \hat{\beta}_1 \bar{X}) - \hat{\beta}_1 X_i \right] = 0$$

整理括號內部：

$$\sum_{i=1}^n X_i \left[ (Y_i - \bar{Y}) - \hat{\beta}_1 (X_i - \bar{X}) \right] = 0$$

拆開求和：

$$\sum_{i=1}^n X_i (Y_i - \bar{Y}) - \hat{\beta}_1 \sum_{i=1}^n X_i (X_i - \bar{X}) = 0$$

現在利用兩個基本的代數離均差恆等式（因為 $\sum (X_i - \bar{X}) = 0$）：

$$\sum_{i=1}^n X_i (Y_i - \bar{Y}) = \sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})$$ $$\sum_{i=1}^n X_i (X_i - \bar{X}) = \sum_{i=1}^n (X_i - \bar{X})^2$$

代回整理即得斜率估計式之最終形式：

$$\hat{\beta}_1 = \frac{\sum_{i=1}^n (X_i - \bar{X})(Y_i - \bar{Y})}{\sum_{i=1}^n (X_i - \bar{X})^2}$$

五、範例題目 (Example Problems)

【經典例題】明瑟工資方程簡化版：教育年數與時薪 計量實證題

題目敘述：
計量經濟學研究者調查了 5 位勞工的受教育年數 $X$（年）與其平均時薪 $Y$（美元），觀測數據記錄如下：

  • 受試者 1：$X_1 = 12$ 年（高中畢業），$Y_1 = 15$ 美元
  • 受試者 2：$X_2 = 14$ 年（大專副學士），$Y_2 = 20$ 美元
  • 受試者 3：$X_3 = 16$ 年（大學學士），$Y_3 = 25$ 美元
  • 受試者 4：$X_4 = 16$ 年（大學學士），$Y_4 = 30$ 美元
  • 受試者 5：$X_5 = 18$ 年（碩士畢業），$Y_5 = 35$ 美元

估計得到的樣本迴歸直線為：

$$\widehat{\text{Wage}}_i = -26.154 + 3.365 \times \text{Education}_i$$

經濟意涵（Economic Interpretation）：

  • 斜率 $\hat{\beta}_1 = 3.365$：在其他條件不變下（ceteris paribus），勞工每多接受 1 年的正規教育，其平均時薪預期將增加約 $3.37$ 美元。此係數衡量了教育的邊際市場回報。
  • 截距 $\hat{\beta}_0 = -26.154$：數學上代表受教育年數為 0 時的預測薪資。但在實質經濟上，樣本數據皆在 12 年以上，在遠離數據範圍的外推時，負薪資並不具實質意義，截距項主要扮演錨定迴歸線通過平均點的幾何角色。

六、重點整理 (Summary & Key Takeaways)

💡 OLS 核心考點精華整理

  • 最小化準則：OLS 透過最小化垂直殘差平方和 $\sum \hat{u}_i^2$，推導出常態方程式。
  • 代數性質三大鐵則（無需任何統計假定即可成立）：
    1. 殘差和為零：$\sum \hat{u}_i = 0$。
    2. 殘差與自變數樣本無關：$\sum X_i \hat{u}_i = 0$。
    3. 樣本平均點 $(\bar{X}, \bar{Y})$ 必然落在迴歸線上。
  • 外生性假定 $E[u \mid X] = 0$ 是關鍵：此假定確保了 OLS 估計量的不偏性（$E[\hat{\beta}_1] = \beta_1$）。若存在遺漏變數、反向因果或測量誤差，導致 $\text{Cov}(X, u) \ne 0$，OLS 估計量將失去一致性與因果詮釋力。
  • 高斯-馬可夫定理 (BLUE)：在五大古典假設下，OLS 是所有線性不偏估計量中效率最高的（變異數最小）。
